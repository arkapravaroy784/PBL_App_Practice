Develop a Java class with an instance variable M1 (TreeMap) and implement the following methods:
1. TreeMap<String, String> saveCountryCapital(String countryName, String capital)
o Add the given country as the key and capital as the value to the TreeMap (M1).
o Return the updated TreeMap.
2. String getCapital(String countryName)
o Return the capital of the given country from M1.
3. String getCountry(String capitalName)
o Return the country corresponding to the given capital from M1.
4. TreeMap<String, String> swapKeyValue()
o Create another TreeMap (M2) where:
 Key = Capital
 Value = Country
o Return M2.
5. ArrayList<String> toArrayList()
o Create an ArrayList containing all country names (keys of M1).
o Return the ArrayList.
Note: Test all the methods using a main() method.
